# Pomodoro Clock ⏱️

A fully functional Pomodoro productivity timer built with 
HTML and JavaScript, completed as part of the Full Stack 
MERN Developer Bootcamp at Matrix Master, Rotterdam.

## What is a Pomodoro Clock?

The Pomodoro Technique is a time management method where 
you work for 25 minutes then take a 5 minute break. 
This app helps you track your work and break sessions.

## Features

- 25 minute work session timer
- 5 minute break timer
- Start, pause and reset functionality
- Visual countdown display
- Automatic session switching

## Technologies Used

- HTML5 — structure and layout
- JavaScript (ES6+) — timer logic and DOM manipulation

## What I learned

- Working with JavaScript timers — setInterval and clearInterval
- DOM manipulation — updating countdown display in real time
- State management — tracking work vs break sessions
- Event handling — start, pause and reset controls
- Building a complete interactive application from scratch

## How to run

1. Clone the repository
2. Open PomodoroClock.html in your browser
3. Click Start to begin your Pomodoro session!
